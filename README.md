# AOS - TP1 — point de départ

## Objectif

Créer de zéro le premier service de PolyShop : une API `product` en mémoire avec Node 22, TypeScript, Express 5, Zod, testée avec Vitest + Supertest et vérifiée par ESLint. À la fin du TP, `npm run lint && npm test && npm run build` passent, et `curl localhost:3001/products/2` renvoie un produit.

Le TP1 démarre **de zéro** : vous créez le projet `product` vous-même (`npm init`).
Suivez `Workbook/01-setup-product.md`. L'état attendu en fin de TP est dans `../../corrections/tp1/product`.
